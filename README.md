# Live-Caption-Notetaker

A clean, accessible web app built for deaf and hard-of-hearing students to view real-time speech-to-text captions alongside a personal class note editor.

## Features
- Live speech-to-text captioning using the browser's built-in Web Speech API.
- Side-by-side note-taking box (stacks cleanly on phones).
- One-click transfer of captured captions into personal notes.
